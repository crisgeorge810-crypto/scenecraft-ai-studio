LEARN AT YOUR PACE

Learning Centre

Practical instructions for using this version of SceneCraft.

01

Start a project

From Dashboard, choose New Project, enter a title and select a format. Your project is saved automatically in this browser.

02

Write your story

Open Script & Story. Select your project, add a logline and write your screenplay. Select Save script when finished.

03

Build scenes

In Storyboard, add scenes, enter shot descriptions and set their duration. Use the up and down arrows to arrange the sequence.

04

Add your media

Use Media Library to import images, video and audio from your device. Browser storage limits vary. Export a backup regularly.

05

Record narration

Open Voice & Audio, allow microphone access and press Start recording. Stop to save the recording to your project.

06

Create subtitles

In Captions, add subtitle text with start and end times. Export .SRT to use in compatible video editors.

07

Preview and export

Timeline Editor previews your scene sequence. Export & Backup lets you download project JSON or render a simple scene-card video.

08

Work offline

Open the app once while online so its files can be cached. Then revisit the installed app or site. Browser support and storage permissions affect offline use.

Important: AI and cloud features

This release is an offline-first creative workspace. It does not claim to generate AI images or AI videos by itself. AI generation requires a connected provider and may have changing free limits. No paid provider or billing account is configured in this package.
